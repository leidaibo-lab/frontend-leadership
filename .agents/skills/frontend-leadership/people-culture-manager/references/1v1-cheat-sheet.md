# 1v1 沟通速查表

> 与[1v1 沟通记录表](../assets/1v1-meeting-template.md)配套使用。先听成员的问题，再核对事实、提供反馈并约定支持，不按“核心”“普通”或“问题”标签决定是否倾听。

## 45 分钟参考节奏

时长可按议题调整；未讨论完的重要问题应约定后续时间和责任人。

| 时间段 | 重点 | 参考表达 |
| --- | --- | --- |
| 0-5 分钟 | 明确议题与上次约定 | “今天你最想解决什么？上次约定的支持落实了吗？” |
| 5-20 分钟 | 理解工作体验与成长事实 | “你承担了什么责任？什么结果值得保留，哪些困难需要一起处理？” |
| 20-30 分钟 | 反馈事实、影响并听取回应 | “我观察到这些事实和影响，你怎么看？有没有需要补充或更正的地方？” |
| 30-40 分钟 | 对齐成长方向与资源 | “接下来想验证什么能力？需要什么责任机会、授权和支持？” |
| 40-45 分钟 | 确认双方行动 | “我们各自承担什么？以什么结果验收，什么时候复核？” |

## 按问题选择沟通方式

| 当前问题 | 沟通重点 | 需要避免的做法 |
| --- | --- | --- |
| 成长方向不清 | 对照职责与职级标准，了解技术或管理方向意愿，选择可验证的实践 | 用头衔、加班或工具数量替代责任成长 |
| 缺少责任机会 | 核对已有任务与授权，明确负责人提供的机会和资源 | 未提供机会便认定能力不足 |
| 工作负荷或协作受阻 | 核实影响，讨论优先级、协作安排及可调整事项 | 将问题全部归因于成员“适应能力” |
| 交付或行为未达要求 | 说明事实与影响，听取回应，约定要求、支持及观察周期 | 贴人格标签、只施压不倾听，或把普通沟通直接变成绩效处分 |
| 成员提出岗位或发展顾虑 | 了解明确诉求，说明可支持范围与需要审批的事项 | 承诺无法兑现的晋升、薪酬或发展机会 |

## 聚焦与收尾表达

- 议题较多：“这些问题都记下了，我们先选今天最需要解决的一项，其余明确跟进时间。”
- 对事实有分歧：“我们先分别记下事实和判断，再找记录核对，暂时不推断动机。”
- 需要转入行动：“为了改善这个问题，你希望我先提供什么支持？我们如何判断它起效了？”
- 时间不足：“这部分还没讨论完，我们约一个后续时间；今天先确认已经达成的行动。”

涉及职级时，以[职级标准](frontend-leveling-standards.md)和[评审基线](frontend-leveling-review-baseline.md)核验；不要从一次对话直接推定定级结论。涉及个人敏感反馈时，按[敏感协作反馈机制](sensitive-collaboration-feedback.md)保护尊严、允许回应并控制信息范围；涉及安全或合规事项转交专业角色。
