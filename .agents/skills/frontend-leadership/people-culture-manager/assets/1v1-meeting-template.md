# 前端团队 1v1 沟通记录表（成长与支持）

> 适用于日常、季度或年度发展沟通。目标是理解成员的工作体验、核对成长事实，并约定双方可执行的支持与改进行动。
> 成长讨论参照[前端岗位职级标准与发展指南](../references/frontend-leveling-standards.md)；正式定级按[评审基线](../references/frontend-leveling-review-baseline.md)执行，单次 1v1 不直接形成晋升或薪酬承诺。

开场参考：

> 今天先聊你希望解决的问题，再一起回顾具体工作和成长，最后确定你和我各自要做的事情。记录会按约定范围保存，你可以更正事实或补充不同意见。不方便分享的个人情况可以不展开。

## 二、成长事实与自我复盘

参考问题：

- “这一阶段哪件事最能体现你的成长？你承担了什么责任，作出了哪些判断？”
- “结果与原来的目标相比有什么变化？有哪些记录能帮助我们核对？”
- “有没有一次取舍或未达预期的结果，值得我们一起复盘？”

| 记录项 | 内容 |
| --- | --- |
| 背景、目标与约束 |  |
| 本人责任 / 团队及协作方贡献 |  |
| 关键判断、备选方案与行动 |  |
| 结果、基线、统计周期与证据出处 |  |
| 后续运行、复用或交接结果 |  |
| 成员自评 / 负责人观察 / 待确认事实 | 分开记录 |

按目标职级的责任范围和六个能力维度讨论，不以工具数量、加班时长、表达风格或单次成绩推定能力。对尚未形成的证据标注缺口；尚未获得责任机会与已有事实表明未达到要求，应分别记录。

## 三、工作体验、机会与支持

参考问题：

- “最近有哪些工作安排让你有成就感？哪些负荷或协作问题需要调整？”
- “接下来你希望承担什么责任？技术深度、业务领域或管理方向，哪一种更符合你的意愿？”
- “为了验证这项能力，需要什么任务、授权、时间和协作支持？我能先解决什么？”
- “关于岗位发展或工作安排，你还有什么希望讨论的顾虑？只说你愿意分享的部分即可。”

记录：

- 成员明确表达的意愿与顾虑：
- 已核实的工作负荷、协作或机会问题：
- 尚待确认的信息及确认方式：
- 负责人可直接提供的支持：
- 需要协调或审批的事项、反馈时间：

技术成长与管理成长具有同等价值；不把带人意愿或人员管理权限作为技术通道的必要条件。负责人须检查是否实际提供过目标责任机会，不能一边不给机会，一边用缺少证据否定成长。

不以提问、拒绝分享隐私或表达不满直接推断离职意愿；如成员主动提出岗位变动意愿，先确认其诉求及可讨论的信息范围，再约定支持或交接安排。

## 四、负责人的具体反馈与成员回应

反馈采用“事实 → 影响 → 期望 → 支持 → 复核”的顺序。

肯定参考：

> 在【具体事项】中，你通过【关键判断和行动】取得了【可核对的结果】。我希望保留和复用的是【具体做法】。

改进参考：

> 在【具体场景】中，我观察到【行为与结果】，对【交付或协作】产生了【影响】。你怎么看？接下来希望达到【明确要求】，我会提供【支持】，我们在【时间】一起看结果。

| 反馈主题 | 事实与影响 | 对应职责或标准条款 | 成员回应 / 事实更正 | 期望、支持与复核安排 |
| --- | --- | --- | --- | --- |
| 值得延续的实践 |  |  |  |  |
| 需要改善的事项 |  |  |  |  |

涉及个人的敏感反馈，按[敏感协作反馈机制](../references/sensitive-collaboration-feedback.md)处理，说明必要事实并保护反馈来源。不用人格标签代替事实，不通过减少机会、公开施压或含糊承诺处理分歧。

## 五、双方行动与成长验证

每次优先确定一至两项行动，明确责任机会、资源和结果；以实际独立承接或问题改善为验收依据。

| 负责人提供的机会或支持 |  |  |  |  |  |
| 成员承担的实践或改进 |  |  |  |  |  |

- 尚未承诺、需要审批的事项及反馈时间：
- 暂未解决的分歧与后续核实人：
- 下次沟通日期：
- 双方确认的记录更正：

涉及正式职级评审时，使用“达到目标职级 / 未达到目标职级 / 证据不足”三种结论，并按评审基线完成核验与校准。能力结论、晋升审批和薪酬安排分别处理；正式绩效改进按公司流程另行沟通。

## 六、必要的跟进记录

仅记录跟进所必需的事实、支持安排和处理状态，区分成员原话、负责人观察与待核实判断。涉及敏感事项时另设受限记录，明确查看权限，不承诺绝对保密，也不保存无关的隐私细节。

- 需要跟进的具体问题与证据：
- 已向成员说明的事实、期望与支持：
- 需协调的角色及必要信息范围：
- 最近复核结果 / 关闭条件：

普通分歧应保留成员回应并约定核实。涉及骚扰、歧视或人身安全等事项，按敏感反馈机制转交专业角色；不继续自行调查。
